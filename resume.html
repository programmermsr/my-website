معرفی

سلام؛ من محمدصادق رضایی هستم و تخصص اصلی‌ام زبان برنامه‌نویسی سی‌شارپ ‎C# است. در ادامه، سه حوزه‌ای که در آن‌ها فعالیت می‌کنم و نمونه‌کارهای مرتبط با هر کدام را معرفی می‌کنم.

💻 توسعه نرم‌افزارهای ویندوز

نرم‌افزارهای ویندوزی را با سی‌شارپ و تکنولوژی Windows Forms طراحی و توسعه می‌دهم. یکی از نمونه‌کارهای من در این حوزه، نرم‌افزار «مدیریت مشتریان و خریدها» است که در ادامه می‌بینید:

💼 سیستم مدیریت مشتریان

سیستم مدیریت مشتریان و خریدها ‎C# · Windows Forms · SQL Server

نرم‌افزار دسکتاپ با Windows Forms برای مدیریت اطلاعات مشتریان، محصولات و خریدها. رمزنگاری رشته اتصال با AES، استفاده از Entity Framework برای اتصال به SQL Server، دریافت داده از Web API، رسم ساعت با دستورات گرافیکی، کامپوننت تاریخ شمسی و مدیریت چاپ با Stimulsoft.

🔗 مشاهده مخزن در گیت‌هاب — برای دیدن کدها github.com/programmermsr/Customers-Purchases-MSR

🌐 توسعه وب

همچنین توانایی طراحی و ساخت وب‌سایت را دارم؛ بخش ظاهری (فرانت‌اند) را با HTML، CSS و JavaScript طراحی می‌کنم، بک‌اند را با ASP.NET Core پیاده‌سازی می‌کنم و با SQL Server و Entity Framework به پایگاه داده متصل می‌شوم. نمونه‌ای از یک وب‌سایت — که در حال حاضر تنها بخش فرانت‌اند آن پیاده‌سازی شده — را می‌توانید در ادامه مشاهده کنید:

🖥️ فروشگاه لپ‌تاپ

فروشگاه لپ‌تاپ (Laptop Store) HTML · CSS · JavaScript

یک فروشگاه لپ‌تاپ کاملاً ریسپانسیو ساخته‌شده با HTML، CSS و JavaScript خالص. دارای فیلتر داینامیک محصولات، شبیه‌سازی سبد خرید و طراحی مینیمال بدون نیاز به بک‌اند.

🚀 مشاهده آنلاین پروژه programmermsr.github.io/laptop-store
🔗 مشاهده مخزن در گیت‌هاب — برای دیدن کدها github.com/programmermsr/laptop-store

📱 توسعه اپلیکیشن اندروید

افعال بی قاعده انگلیسی
